
# 🎉 Registro Día del Niño - App Web

Este proyecto es una aplicación web creada con **Streamlit** para registrar empleados e invitados para el evento "Día del Niño".

---

## 📦 Contenido del repositorio

- `app_dia_del_nino.py` — App principal en Streamlit.
- `empleados.xlsx` — Base de datos de empleados (puedes editarla).
- `LOGO DE BATESVILLE 2024.png` — Logo mostrado en la parte superior.
- `requirements.txt` — Requisitos para ejecutar la app.

---

## 🚀 ¿Cómo publicar esta app en Streamlit Cloud?

1. **Crea una cuenta** en [https://streamlit.io/cloud](https://streamlit.io/cloud) usando tu cuenta de GitHub.

2. **Crea un nuevo repositorio** en GitHub y sube todos estos archivos.

3. En [Streamlit Cloud](https://streamlit.io/cloud):
   - Haz clic en “New app”.
   - Selecciona tu repositorio.
   - Asegúrate de que el archivo principal sea `app_dia_del_nino.py`.
   - ¡Haz clic en “Deploy”! 🎉

4. Streamlit generará una **URL pública** para compartir la app con quien quieras.

---

## 🖥️ Ejecución local (opcional)

Si quieres correrlo en tu computadora:

```bash
pip install -r requirements.txt
streamlit run app_dia_del_nino.py
```
